## Multimodal Arrhythmia Risk Stratification

CNN + Bio-ClinicalBERT + CGA fusion framework for ECG-based 
arrhythmia risk stratification on MIMIC-IV dataset.

### Results
- Macro AUC: 0.9859
- Accuracy: 94.94%
- Severe-class Recall: 95.92%
